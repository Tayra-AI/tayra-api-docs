# Welcome to Tayra API Docs

**Tayra.ai** is an AI-powered medical assistant startup that listens to doctor-patient conversations and automatically writes clinical notes and reports in real time.

## Getting Access

To get API access and integrate with Tayra, please [contact our sales team](https://www.tayra.ai/contacts).

## Integration Options

Tayra offers two integration modes. [**Visit API**](visit.md) is a batch API — you upload a pre-recorded audio file and receive a structured clinical note. [**Embedded Page**](embedded-page.md) is a real-time flow — you embed a Tayra view into your app where the clinician records, reviews, and submits the note during the consultation.
